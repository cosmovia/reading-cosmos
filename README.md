# 🌌 Reading Cosmos Pro MAX

> Build your own reading universe.

Reading Cosmos Pro MAX 是一个 AI 驱动的阅读管理系统。

## AI Gateway（v4.4 Batch 3）

书籍内容概要与笔记思考建议统一通过已登录用户专用的 Supabase Edge Function 生成。Gateway 会验证书籍所有权；内容概要会缓存，相同输入的缓存命中不占每日 10 次额度。笔记辅助每日 20 次，仅返回当前编辑会话中的临时建议，建议正文不写入书籍、缓存或调用日志，退出编辑或保存笔记后即清除。首次使用笔记辅助前会说明数据处理方式并记录用户同意。

Gateway 已具备多模型路由、限流重试与熔断结构。GLM 是主路由；配置 OpenRouter 后，仅不含用户笔记的书籍内容概要可在 GLM 遇到可恢复故障时自动切换到 OpenRouter 免费模型。笔记辅助与整库阅读洞察仍只使用 GLM，不会被自动发送给 OpenRouter。

路由可靠性按供应商独立记录熔断状态，并仅在限流、超时、网络故障、服务不可用或熔断冷却等可恢复错误上尝试后续路由。鉴权、余额与请求格式错误不会自动切换供应商。生成记录保存实际供应商、模型、fallback 顺序与总尝试次数。只有配置相应 Secret 后路由才会启用；OpenRouter 通过 `openrouter/free` 在当前可用的免费模型中路由，并记录实际返回的模型名称。

跨供应商自动 fallback 当前只允许用于不含用户笔记的书籍内容概要。每条供应商路由还必须显式声明允许处理的任务，因此即使主供应商 Key 缺失，笔记辅助和整库阅读洞察也不会落入只允许概要的备用供应商。后续必须经过单独的隐私授权才能扩大范围。服务状态按内容概要、笔记辅助和阅读洞察分别报告可用性。路由策略、真实执行顺序、失败元数据与供应商隔离熔断由 `provider-routing.test.ts` 覆盖，可在 `supabase/functions/ai-gateway` 中执行 `deno task test`。

设置中心会通过不调用模型的 `service_status` 任务展示当前平台模型、服务状态、各类每日额度及刷新时间。该状态查询不会写入生成记录或消耗额度。限流、超时、熔断冷却与平台配置异常会转换为用户可行动的提示；个人 BYOK 目前仅作为书籍概要的可选替代。

设置中心的“测试备用路由”只在用户主动点击时向 OpenRouter 发送固定的 `READY` 连通性请求，不包含书籍、笔记、书架或账号资料。探测结果展示实际命中的免费模型，同一运行实例内设有 5 分钟冷却；探测不写入生成记录，也不占 Reading Cosmos 的任务额度。

书籍封面采用规则化元数据链路，不调用大模型。新增书籍会根据书名与作者查询 Open Library，并在其不可用或没有可信匹配时回退 Google Books；只有通过标题/作者匹配阈值的 HTTPS 封面才会写入现有 `books.cover_url`。旧书在打开详情时按需补齐，结果云端缓存并跨设备复用；查询失败或图片失效时继续显示原有分类艺术封面。

阅读洞察由规则层与 AI 层共同组成：阅读数量、分类占比和月度趋势始终由本地数据确定性计算；阅读人格解释、认知焦点、延伸路线和年度叙事通过 Gateway 生成。洞察按书架与笔记内容哈希缓存，普通查看不调用模型，用户主动重新分析每日最多 3 次。首次分析前需单独确认整库阅读数据的处理范围，结果存入用户隔离的 `ai_artifacts` 以支持跨设备查看。

部署前须在 Supabase Dashboard 的 Edge Function Secrets 中配置：

- `GLM_API_KEY`：平台智谱 API Key，禁止提交到 Git。
- `GLM_MODEL`：可选，默认 `glm-4.7-flash`。
- `OPENROUTER_API_KEY`：可选的书籍概要免费备用路由 Key，禁止提交到 Git。
- `OPENROUTER_MODEL`：可选，默认 `openrouter/free`；也可指定单个 OpenRouter 免费模型 ID。

迁移与部署顺序：先执行 `supabase/migrations`，再部署 `ai-gateway`，确认 Secret 后才发布前端。回滚时先恢复旧前端，再回滚 Gateway；`books.ai_data.overview` 兼容镜像保证已生成概要仍可显示。

它诞生于一个非常简单的问题：

> 当阅读发生在手机、电子阅读器、纸质书、图书馆等不同渠道时，我们如何能够轻松记录所有阅读，并真正把知识沉淀下来，而不是停留在「读过」？

Reading Cosmos 希望成为这个答案。

它不仅帮助你管理读过的书，更希望帮助你构建属于自己的知识宇宙，让每一本书、每一个观点、每一次思考彼此连接，并最终形成持续成长的认知网络。

# 📖 Reading Cosmos 阅读方法

Reading Cosmos 并不追求记录得越多越好，而是希望用更轻量、更适合不同类型书籍的方式帮助阅读真正发生。

因此，根据不同类型的书籍，采用不同的阅读记录方式。

---

## 🛠 工具类书籍

采用 **第一性原理式阅读法（First Principles Reading）**。

围绕三个核心问题展开：

- **What Problem（解决什么）**
  > 这本书试图解决什么问题？

- **With What（用什么工具）**
  > 作者提出了哪些方法、模型或工具？

- **Why This Tool（为什么有效）**
  > 为什么这个方法能够起作用？它背后的第一性原理是什么？

相比记录大量内容，更关注理解底层逻辑。

---

## 📚 小说 / 人文 / 非虚构作品

采用 **R-A-T 内化笔记法**。

### R · Resonate（共鸣）
- 记录最触动自己的：人物、情节、概念
> 回答：谁触动了我？

### A · Abstract（提炼）
- 提炼三个最重要的思想/值得长期记住的金句
> 回答：它告诉了我什么普世真相？

### T · Transform（转化）
- 记录阅读后的启发/可以实践的行动
> 回答：阅读之后，我会变成一个怎样不同的自己？
